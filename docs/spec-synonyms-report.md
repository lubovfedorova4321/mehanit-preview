## Решения

Импорт ТЗ-02 в Payload **уже выполнен** (`import-report.json`, 11.09.2026: 156 параметров,
41 раздел, 813 станков; две карточки пропущены как «изменённые в админке»). Поэтому seed не
правился — изменения подготовлены как скрипт для базы:
`mehanit-site/src/scripts/fix-spec-params.ts`.

Запуск: `pnpm payload run src/scripts/fix-spec-params.ts` — сухой прогон, ничего не пишет;
`--apply` — записать; `--single-to-main` — дополнительно перенести семь значений без
контршпинделя в главный шпиндель. Скрипт идемпотентен, проверяет использование перед удалением.

### 1. Разделение частоты вращения шпинделей

`spindle_speed_main_sub` (23 карточки, все — автоматы продольного точения) разделяется на
`spindle_speed` (главный) и новый `sub_spindle_speed` «Частота вращения контршпинделя»
(об/мин, range). Разбор значения: слеш внутри «об/мин» разделителем не считается.

**Раскладывается однозначно — 12 карточек:**

| Карточка | Главный шпиндель | Контршпиндель |
|---|---|---|
| turning-s205, s206, s265, s266, sl205, sl265 | 10000 об/мин (8000 с вращ. втулкой) | 10000 об/мин |
| turning-sl325, sl326 | 8000 об/мин (6000 с вращ. втулкой) | 8000 об/мин |
| turning-sl385, sl386 | 6000 об/мин | 8000 об/мин |
| turning-sl125 | 12000 об/мин (8000 с вращ. втулкой) | 12000 об/мин |
| turning-ss-20rb-rby | 10000 об/мин¹ | 8000 об/мин |

¹ В исходнике «10000/8000 об/мин» единица указана один раз — скрипт дописывает её первой части.

**Одно значение, контршпиндель не указан — 7 карточек** (по умолчанию не трогаются,
переносятся в главный шпиндель только с флагом `--single-to-main`):
`turning-ss-12rb-rby` (12000 об/мин), `turning-ss-20a-20as`, `turning-ss-20-20a`,
`turning-ss-20ab-ast` (15–8000 об/мин), `turning-sl203`, `turning-sl263`
(10000 об/мин (8000 с вращ. втулкой)), `turning-csl1203ii` (8000 об/мин (6000 с вращ. втулкой)).

**Не раскладывается однозначно — 4 карточки, оставлены как есть:**

| Карточка | Значение | Почему |
|---|---|---|
| turning-ss-206e | 8000 / 8000 / 7000 / 6000 об/мин | четыре значения подряд, не «главный/контр.» |
| turning-ss-205e | 8000 / 8000 / 6000 / 6000 об/мин | то же |
| turning-ss-32rb | 7000 об/мин (модели 32) / 6000 об/мин (модели 42) | разделение по моделям, а не по шпинделям |
| turning-ss-32a | 200–7000 об/мин (200–6000 для типа 42) | то же |

### 2. Удаление неиспользуемых определений

К удалению: `max_turning_length_guide`, `feed_rates`, `x_maksimalnyy_hod_shpindelya`,
`x_vysota_shpindelya`, `x_vmestimost_obrabatyvaemyh_detaley`, `x_podacha_vozduha`,
`x_energopodacha`.

Проверка по seed: ссылок в шаблонах подразделов (`categories.json`) нет ни на один код,
в карточках не используются. Скрипт повторяет эту проверку уже по базе — сверяет
`machines.baseSpecs`, `machines.models[].baseSpecs` и `categories.specTemplate`, и удаляет
только то, на что ссылок нет; иначе печатает, кто использует, и параметр остаётся.

### 3. Три группы — отчёт без изменений

Все три оказались не синонимами: параметры применяются в непересекающихся подразделах.

| Группа | Где используется | Пересечения |
|---|---|---|
| `main_motor_power` (12 карточек) | Токарно-карусельные (8), Гильотинные ножницы (4) | карточек, где заполнены и `main_motor_power`, и `spindle_power` — **0** |
| `grinding_diameter` (17 карточек) | Бесцентровошлифовальные станки (17) | пересечений с `id_grinding_diameter` / `od_grinding_diameter` — **0** |
| `throat_depth` (4 карточки) | Гильотинные ножницы (4) | значения: «80–100 мм» ×3, одно пустое |

`throat_depth` («вылет» у гильотинных ножниц) и `spindle_reach` («вылет шпинделя до колонны»)
совпадают только по алиасу «вылет» — это разные величины.

### 4. «Длина точения» по типу втулки

Не трогается: `max_turning_length_fixed_guide`, `_no_guide`, `_rotating_guide` — разные
параметры, в группу попали только из-за удаления скобок при нормализации. Четвёртый,
`max_turning_length_guide`, не используется нигде и входит в список на удаление (п. 2).
