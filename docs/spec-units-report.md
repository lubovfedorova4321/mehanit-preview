# Единицы измерения характеристик: сверка пилота с каталогом

Проверка отчёта пилота (значения без единиц в таблицах карточек) по данным импорта:
`seed/spec-params.json` (определения параметров) и `seed/machines.json` (значения), seed v5.

## Итог

**Реальных пробелов в данных каталога нет.**

- Уникальных параметров в отчёте пилота — **63** (1088 строк, 224 карточки).
- У **59** единица уже задана в определении параметра — новый сайт подставит её при выводе,
  в данных править нечего.
- Оставшиеся **4** — обозначения конусов (`№5`, `80#`, `1:20`, `68 (1:4)`), единица к ним
  неприменима; в seed у них корректный `valueType: text`.

Все 1088 строк сверены с `machines.json` по `legacy.pilotSlug`: значения совпадают
один в один (одно расхождение — лишние пробелы). То есть пилот показывает ровно то, что
лежит в seed, и единицы теряются не при выводе, а отсутствуют в самих значениях —
но восполняются из определения параметра.

Файл «Технические характеристики.xlsx» как источник единиц не подходит: это перечень
характеристик по подкатегориям (366 пунктов), единиц измерения в нём нет.
